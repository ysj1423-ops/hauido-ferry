# 하의도 배편

목포 ↔ 하의도(웅곡)·신의도(상태동리·상태서리) 배편별 운항 예상과 공식 발표를 보여주는 사이트.

- 사이트: https://ysj1423-ops.github.io/hauido-ferry/
- 30분마다 GitHub Actions가 `scripts/collect.mjs`를 실행해 `docs/data/latest.json`을 갱신합니다.

## 자료
- 한국해양교통안전공단 여객선 운항상태 정보 (공공데이터포털 15142304) — 배편별 공식 운항/통제, 과거 실적
- 기상청 해양기상정보 단기 해상예보 (전남중부서해앞바다) — 최신 발표 + 과거 발표분(학습용)
- Open-Meteo — 4개 기상 모델 7일 예보, 과거 예보 아카이브, 파고

## 예측
배편 출항 전후 풍속·돌풍·파고·시정 예보와 기상청 해상예보를 특징으로, 과거 실제 운항(0)·통제(1)를 학습한 로지스틱 회귀(배별 절편 + 공통 기울기).
비운항(선사 사정)은 학습에서 제외. 시간순 검증(앞 70% 학습, 뒤 30% 평가) 결과를 사이트에 표시.

## 설정 (저장소 Settings → Secrets and variables → Actions)
- `DATA_GO_KR_KEY` (필수): 공공데이터포털 인증키(Decoding 키)
- `NTFY_TOPIC` (선택): 공식 발표가 바뀌면 ntfy.sh 해당 주제로 휴대폰 알림
